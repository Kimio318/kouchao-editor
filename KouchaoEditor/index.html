本程序已把 ffmpeg 与 whisper 语音识别（含 ggml-base.bin 模型） 全部打包在内，无需联网、无需安装，拷到任意 Windows 电脑双击「口播剪辑器.exe」即可用，视频全程只在本机处理。
• 去静音 / 长停顿：调用内置 ffmpeg.exe，本地完成。
• 语气词切除（嗯/啊/那个…）：调用内置 whisper.cpp 本地识别，视频不出本机；分「安全级 / 语境级」两级，切点吸附到停顿边界，避免误伤。
• 停顿压缩：长停顿可压成短间隙，保留自然呼吸感（可选）。
• 自然切片：按长静音自动切成多段视频（可选）。
• 字幕 & 文案输出：启用「语气词切除」（即语音识别）后，分析时会同步识别视频文案；剪辑完成的结果除成品视频外，还会附带 SRT / VTT 字幕文件 与 文案 (.txt)（多段时为 zip 压缩包，单段时也是含字幕的 zip）。字幕时间戳已按剪辑后的时间轴重新对齐，被切掉的语气词/静音处不出现字幕。
• 关闭启动窗口即退出程序。若杀毒软件误报，请允许运行（程序不含任何上传行为）。
内置的是 ggml-base.bin（6 档里第 2 小），够用于普通话去语气词，但识别粤语会明显跑偏，也更容易在长视频后半段「复读崩溃」。
换模型方法：下载下面任一 .bin，放进本程序目录的 whisper\models\，刷新页面即可（程序会自动选档位最高的那个，无需删旧模型、无需重启）。
• 粤语必须用 large-v3 系：Whisper 的粤语是独立语言标记 <|yue|>，只存在于 large-v3 的词表里（词表 51866；其余模型都是 51865，没有粤语）。
  — ggml-large-v3-turbo.bin（约 1.6GB）← 最推荐，支持粤语；CPU 上比 base 慢数倍，长视频需耐心等待（可放进本程序 whisper\models\ 目录，程序会自动选用）
  — ggml-large-v3.bin（约 3.1GB）精度最高，但 CPU 上慢很多
• 只做普通话、想省空间：ggml-medium.bin（约 1.5GB）或 ggml-small.bin（约 0.5GB）
