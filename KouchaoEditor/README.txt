口播自动剪辑器（便携版）使用说明
================================

【启动】
  直接双击本文件夹里的「口播剪辑器.exe」即可。
  （也可双击 start.bat 启动。）
  启动后会自动打开浏览器，进入剪辑页面；如未自动打开，
  请手动在浏览器地址栏访问启动窗口里显示的地址（默认 http://127.0.0.1:8021/）。

【使用】
  1. 把视频拖入页面，或填写本机视频路径（如 E:\口播测试\260806.mp4）。
  2. 调好参数，点「分析」。
  3. 点「开始剪辑」，完成后点页面上的下载链接保存结果。
     若勾选了「语气词切除」（即启用语音识别），结果除成品视频外，
     还会附带 SRT / VTT 字幕文件与「文案 .txt」——字幕时间戳已按剪辑后的
     时间轴重新对齐，被切掉的语气词/静音处不再出现字幕。

【参数说明】
  · 静音阈值 / 最小剪切停顿：控制去静音的灵敏度。
  · 边缘留白 / 最短保留：防止切掉字头字尾、滤掉杂声碎片。
  · 停顿处理：
      - 切除：直接去掉静音（最紧凑）。
      - 压缩：把长停顿压到「压缩后间隙」长度的短停顿，保留自然呼吸感。
  · 语气词切除（可选，需 whisper 识别）：
      - 安全级词表：无意义犹豫音，始终切除。
      - 语境级词表：连接/顺序词，仅贴近停顿边界时才切，避免误伤正常语句。
      - 切点会自动吸附到最近的停顿边界，不切在发音中途。
      - 分析时会同步识别视频「文案（口播稿）」，结果页可直接查看并下载 .txt；
        剪辑完成后，成品除视频外还附带 SRT / VTT 字幕文件（字幕按剪辑后时间轴对齐）。
      - 识别语言可选：自动 / 中文（普通话）/ 粤语 / 英文。
      - 内置「复读崩溃」防护：whisper 在长视频后半段可能把同一句复读十几遍
        （模型能力不足导致的解码崩溃）。程序已关闭跨段文本条件化并自动清理复读，
        若仍检测到明显复读会在结果页给出复读率告警。
  · 识别处理方式（可选）：
      - CPU + GPU 处理（默认）：若 whisper 构建带 GPU 后端，会用显卡加速识别。
      - 仅用 CPU 处理：强制只用 CPU（相当于给 whisper 加 --no-gpu）。
      - ⚠ 当前内置的 whisper 是纯 CPU 构建，没有 GPU 后端，因此选「CPU+GPU」
        也会回退到 CPU，不会真正用显卡。页面顶部「语音识别就绪」一行会如实显示
        GPU 是否可用。要真正用显卡加速，需自行替换一个带 GPU 后端（Vulkan/CUDA 等）
        的 whisper-cli.exe 到本程序目录的 whisper\ 文件夹。
  · 自然切片（可选）：勾选后，超过「切片停顿阈值」的静音视为话题断点，
      自动把视频切成多段，结果打包成 zip 下载。

  · 输出画质（可选）：三档可选，默认「高质量」
      - 高质量：CRF 18 + preset medium + 音频 192k（接近原片画质，文件较大）
      - 均衡：CRF 23 + preset medium + 音频 160k（libx264 默认值附近，画质/大小折中）
      - 高速小文件：CRF 28 + preset veryfast + 音频 128k（最快、文件最小、画质有损）
    原片是高码率（>5000 kbps）素材时建议选「高质量」；要分享压缩包或低码率原片可选后两档。

【退出】
  关闭「口播剪辑器」那个黑色窗口即可完全退出。

【携带到其他电脑】
  把整个「KouchaoEditor」文件夹复制 / 拷贝到任意 Windows 电脑，
  双击「口播剪辑器.exe」即可使用，无需安装 Python、无需联网、无需下载任何东西。

【识别不准 / 要识别粤语 —— 换模型】
  内置的是 ggml-base.bin（whisper 六档里第二小）。它够用于普通话去语气词，
  但识别粤语会明显跑偏，长视频后半段也更容易复读崩溃。

  ★ 粤语必须用 large-v3 系模型 ★
    Whisper 的粤语是一个独立语言标记 <|yue|>，它只存在于 large-v3 的词表里
    （词表大小 51866）。其余所有模型（tiny/base/small/medium/large-v1/v2）
    都是 51865，根本没有粤语这个语言 —— 只能按普通话硬解，于是就出现
    「而家」被听成「延載」、「睇」被写成「採讀」这类音近字乱码。
    程序会自动检测：模型不含粤语时，选「粤语」会降级为普通话解码并明确提示。

  换模型方法（很简单）：
    1. 下载下面任一 .bin 文件
    2. 放进本程序目录的  whisper\models\
    3. 刷新浏览器页面即可（程序自动选档位最高的那个，
       不用删旧模型、不用重启程序）

  推荐（都支持粤语；程序会自动在同档位里挑体积最小的量化版，所以放进 q8_0 就会用它而非 f16 原版）：
    · ggml-large-v3-turbo-q8_0.bin （约 0.85GB）← 最推荐：turbo 本就比 large-v3 快，q8_0 量化后体积减半、
        质量几乎无损、CPU 推理比 f16 原版快约 1.5~2 倍，长视频更不容易超时。
    · ggml-large-v3-turbo-q5_0.bin （约 0.55GB）  还想更快更小可换 q5_0，质量有轻微损失，粤语基本可用。
    · ggml-large-v3-turbo.bin （f16 约 1.6GB）  质量上限，但 CPU 上最慢、最易超时
        （本程序已把它备份为 _old_ggml-large-v3-turbo.bin，不会被自动选用，需要时可改回原名）。
    · ggml-large-v3.bin       （约 3.1GB）  精度最高，但 CPU 上更慢、容易超时。
    · ggml-medium.bin         （约 1.5GB）  只做普通话时的性价比之选（无粤语）。
    · ggml-small.bin          （约 0.5GB）  想省空间时的最低可用档（无粤语）。

  下载地址（Hugging Face 官方仓库）：
    huggingface.co/ggerganov/whisper.cpp  →  Files  →  找对应文件名下载

  程序会自动「按语言选模型」：
    - 选「粤语」且目录里有 large-v3 系模型时 → 自动用大模型以粤语解码（真正识别粤语）；
    - 选「中文 / 英文」→ 用内置的 ggml-base.bin（更快）。
  所以放进 large-v3-turbo 后，粤语会变准，而普通话剪辑速度不受影响。

【粤语转写校正（内置）】
  即便用了 large-v3 系模型 + 粤语解码，whisper 仍常把粤语读音「写成普通话书面语」
  （如 他們→佢哋、還有沒有→有冇、我們→我哋）或「音对字错」
  （如 牽花板→天花板、人知→認知、資迅→資訊、基義→AI）。
  这些大多是落字错误而非口音问题，程序在识别完成后会用一份「粤语常见错写校正表」
  自动修正（仅对粤语输出生效，不影响普通话）。你之前贴出的样稿里这类偏差基本都能被兜住。

  ⚠ 关于「粤语提示词」：本程序会给 whisper 传一段粤语引导提示词（initial prompt）进一步
  压低普通话书面语泄漏。但提示词是中文，须经命令行传给 whisper-cli.exe；在中文 Windows 默认的
  GBK 代码页下，中文经命令行会被按 GBK 字节传、被 whisper 当 UTF-8 误读成乱码。因此程序在 GBK
  系统上会自动跳过提示词（页面顶部「语音识别就绪」一行会说明），改由上面的校正表兜底。
  若想让提示词也原生生效，可在 Windows「设置 → 时间和语言 → 语言和区域 → 管理语言设置 →
  更改系统区域设置」中勾选「Beta: 使用 Unicode UTF-8 提供全球语言支持」并重启，
  届时中文提示词会原原生效，无需改动任何文件。

【说明】
  - ffmpeg 与 whisper 已全部打包在内；whisper 模型位于本程序目录的 whisper\models\ 下：
    内置 ggml-base.bin，粤语模型为 ggml-large-v3-turbo-q8_0.bin（原 f16 版已备份为
    _old_ggml-large-v3-turbo.bin，不被自动选用）。要换更小/更快模型，把对应 .bin 放进
    该目录、刷新页面即可。
  - 所有处理均在本地完成，不上传任何服务器。
  - 如被杀毒软件误报，请选择“允许运行 / 加入白名单”；本程序不含任何上传行为。
  - 默认端口 8021；如被占用会自动顺延（8022、8023……），以启动窗口提示为准。
